            <version>3.5.6</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>

        <dependency>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
            <version>2.15.0</version>
        </dependency>
    </dependencies>
</dependencyManagement>
稳定性优先级
RELEASE（无后缀） > M（Milestone） > SNAPSHOT。

## 开发细节

### 1.前后端传参

前端：

1.<font color=red>**params**</font>（**自动转换为 URL 查询参数拼接到 URL 后面**?key1=value1&key2=value2）

```java
后端接收方式
1.@GetMapping("/api/user")
  public String getUser(
    @RequestParam("id") Long userId, // 接收查询参数 id，指定参数名（与前端 key 对应）
    @RequestParam(value = "name", required = false) String userName // required = false 表示非必传
) 

2.// 定义实体类接收参数
@Data // Lombok 注解，自动生成 getter/setter
public class UserQuery {
  private Integer page;
  private Integer size;
  private Integer status;
}

@GetMapping("/api/user/list")
public String getUserList(UserQuery query) { // 参数较多时直接用对象接收，参数名自动匹配
}
```



2.<font color=red>**data**</font>（**默认** **JSON 数据{ }**'Content-Type: application/json'，

**混合表单数据FormData**'Content-Type': 'Content-Type: multipart/form-data' ，

**简单键值对传输**`application/x-www-form-urlencoded`）

```java
1默认 JSON 数据.@RequestBody
2混合表单数据.@PostMapping("/api/upload")
public String upload(
    @RequestParam("username") String username, // 接收普通文本字段
    @RequestParam("avatar") MultipartFile avatar // 接收文件（MultipartFile 是 Spring 提供的文件对象）
) 
3.简单键值对传输绑定到对象@ModelAttribute（推荐参数较多时）或用@RequestParam
```



3.<font color=red>**路径传参**</font>（@PathVariable）

总结

| 前端传参方式                    | 核心特征                                                     | 后端接收注解 / 类型                                         | 典型场景                     |
| ------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------- | ---------------------------- |
| `params`（查询参数）            | URL 后拼接？key=value                                        | `@RequestParam` 或实体类                                    | GET 请求筛选、分页           |
| `data`（JSON）                  | 请求体为 JSON 对象，Content-Type: application/json           | `@RequestBody` + 实体类                                     | POST/PUT 提交复杂数据        |
| `data`（FormData）              | 含文件或混合数据，Content-Type: multipart/form-data          | `@RequestParam` + `MultipartFile`（文件）/ 普通类型（文本） | 文件上传、混合表单提交       |
| `data`（x-www-form-urlencoded） | 请求体为 key=value&...，Content-Type: application/x-www-form-urlencoded | `@RequestParam` 或 `@ModelAttribute` + 实体类               | 简单表单提交（登录、搜索）   |
| 路径传参                        | URL 路径中嵌入参数（/api/user/{id}）                         | `@PathVariable`                                             | RESTful 接口（查询单个资源） |

### 2.前后端对null值和""的判断时机

前端

1. 用户输入时（表单 / 交互场景）：即时校验空值
2. 请求发送前（数据格式化）：按后端要求转换空值
3. 接收后端数据后（渲染前）：处理显示异常

后端

1. 接收前端数据时（参数校验）：严格校验空值合法性

2. 业务处理时（数据转换）：统一空值格式

3. 数据存储时（数据库交互）：按字段约束处理

4. 返回数据给前端时（格式化输出）：统一空值表现

5. ```xml
   <!--validation依赖-->
           <dependency>
               <groupId>org.springframework.boot</groupId>
               <artifactId>spring-boot-starter-validation</artifactId>
           </dependency>
   自动整合参数校验所需的依赖和配置，让你可以直接在项目中使用 @Valid(嵌套校验)、@Validated（分组校验） 以及 javax.validation.constraints 包下的校验注解（如 @NotBlank、@NotNull 等），无需手动引入零散的校验依赖。
   ```
